# 🎓 Student Exam Score Predictor

A machine learning-powered web application built with Python, Streamlit, and Scikit-Learn that predicts a student's expected exam score based on various performance and lifestyle factors.

---

## 🚀 About the Project
This project leverages Machine Learning (Random Forest Regressor) to analyze student data and provide real-time score predictions. It features an interactive, user-friendly web interface built using **Streamlit**, allowing users to adjust parameters via sliders and instantly view expected outcomes.

---

## ✨ Key Features
- **Real-Time Predictions:** Enter study habits and instantly get predicted exam scores.
- **Interactive UI:** User-friendly sliders for inputting study hours, attendance, previous scores, and sleep hours.
- **Machine Learning Model:** Powered by a robust `RandomForestRegressor` trained directly on dataset metrics.
- **Cloud-Ready Deployment:** Fully optimized for seamless deployment on Streamlit Community Cloud and GitHub.

---

## 📂 Repository Structure
- `app.py`: Contains the core Streamlit web application code and machine learning training/prediction logic.
- `requirements.txt`: Lists all essential Python packages and dependencies (`streamlit`, `pandas`, `scikit-learn`, `joblib`).
- `student_performance_messy.csv`: The primary dataset used for training the model and handling data inputs.
- `README.md`: Comprehensive documentation outlining project details, features, and usage instructions.
